UnityBuilder 개인정보처리방침

시행일: 2026년 11월 13일

1. 어떤 Google 정보를 쓰나요

UnityBuilder 는 Google 드라이브 권한 중 drive.file 하나만 요청합니다. 이 권한으로는 UnityBuilder 가 직접 만든 폴더와 파일만 보고 고칠 수 있으며, 드라이브의 다른 파일은 볼 수 없습니다. 로그인할 때 어느 계정으로 올리는지 보여 주려고 계정 이메일 주소를 한 번 읽습니다.

2. 무엇에 쓰나요

  • 빌드한 APK 파일을 로그인한 계정의 드라이브 UnityBuilder 폴더에 올립니다.
  • 그 폴더를 설정에 적어 둔 팀원 계정에만 보기 권한으로 공유합니다.
  • 같은 게임의 오래된 APK 는 최근 몇 개만 남기고 지워 드라이브 용량을 아낍니다.

이 밖의 목적으로 Google 정보를 쓰지 않습니다. 광고, 분석, 판매에 쓰지 않습니다.

3. 어디에 저장하나요

로그인 열쇠(refresh token)는 UnityBuilder 를 실행하는 Mac 안의 파일 하나에만 저장하며, 그 Mac 의 사용자만 읽을 수 있게 둡니다. 개발자나 다른 서버로 보내지 않습니다. UnityBuilder 는 Google 외의 곳에 Google 정보를 보내거나 공유하지 않습니다.

4. 지우는 방법

  • Mac 의 gdrive_token.json 파일을 지우면 UnityBuilder 가 더는 드라이브에 접근하지 못합니다.
  • Google 계정의 서드 파티 앱 및 서비스 화면에서 UnityBuilder 의 권한을 언제든 거둘 수 있습니다.
  • 올라간 파일은 드라이브의 UnityBuilder 폴더에서 직접 지울 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

UnityBuilder 가 Google API 에서 받은 정보를 쓰고 다른 앱으로 옮기는 일은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구 사항을 따릅니다.
